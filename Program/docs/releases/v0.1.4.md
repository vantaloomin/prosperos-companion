Fixes from two rounds of hands-on testing with real AI models and live sources, plus editable prompts for power users. If you have an earlier version, install over it (or run `update.bat` / `update.command` in a Git clone); your companion and everything they remember are kept, and the first launch makes a verified backup before updating.

## What's new

- **Edit the core prompts.** Turn on **Show advanced settings** under the Settings tabs to get an Advanced tab with the chat character prompt, texting first, life phrasing, memory suggestions, picture description and the four character drafting prompts. Each shows its default and the placeholders it needs, and has Reset to default. If a later update changes a default you've reworded, the app points it out and leaves your version alone.

## What's fixed

**Chat and staying in character**
- Out-of-character questions (`OOC:` or ((double parentheses))) now get a plain answer from the model itself instead of an in-character one.
- In-character replies no longer slip in ((asides)) or "I don't have access to real-time data".
- An OpenRouter "too many requests" error is retried once instead of failing the reply.

**Real-world lookups**
- Sports schedules work again (ESPN changed how it answers date ranges), "Are the Ravens playing this week?" now looks it up, and Local Pulse lists your teams' away games too.

**Memory**
- More gets remembered: jobs like "I work nights as a 911 dispatcher" or "moved to Denver for a nursing job", and details about people said with contractions or after "and she".
- Sentences the memory rules miss are sent for a model suggestion even when a rule matched something else in the same message.

**Character and life**
- Help me write no longer puts raw JSON into a field, and a reply cut off at the length limit is retried instead of failing.
- A drafted home is in the place the character is said to live, and its rent fits. Biologist is a new career, and surf instructor only appears in cities with a beach or surf school.
- Fixed first texts follow the character's lowercase style when they have one.
- Life events no longer copy clock times from the routine into their wording, and waterfront walks stay outdoors.
- A married sibling no longer gets an engagement storyline.

**Interface**
- Switching companions (or Start over and Delete) keeps you on the page you were on instead of jumping back to Character.
- Start over and Delete count the companion's messages too, the Feed header keeps the "N new" count you arrived with, and an empty "Since you were last here" points at events waiting for Keep.
- A photo of what your companion is doing right now matches the event later written for that moment.

## Install on Windows

**Installer (easiest):** download `ProsperoCompanion-0.1.4-win-x64-setup.exe` below and run it. It installs for your user only, needs no administrator rights, Python or Node, and adds Prospero Companion to the Start menu. It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC": click **More info**, then **Run anyway**.

**Portable:** `ProsperoCompanion-0.1.4-win-x64.zip` is the same app without an installer. Unzip it anywhere and double-click `Prospero Companion.cmd` in the `ProsperoCompanion` folder.

**From source:** download the source code below (or `git clone` the repository), open the `Windows` folder, double-click `install.bat` once and then `launch.bat`. A Git clone can update itself later with `update.bat`.

Then open **Settings > Models**, add a model, and create your companion. `SHA256SUMS.txt` lists the checksums of the downloads.

## Install on a Mac

There's no Mac app yet. Download the source code below (or `git clone` the repository), open the `Mac` folder and double-click `install.command`, then `launch.command`. It needs Python 3.12+ and Node.js 22.13+ and installs them with Homebrew if you have it. The scripts aren't signed, so a downloaded ZIP needs **Open Anyway** in System Settings > Privacy & Security the first time; [Installing on a Mac](https://github.com/vantaloomin/prosperos-companion/blob/main/Program/docs/macos.md) walks through it.

Your companion's data lives outside the program folder (`%LOCALAPPDATA%\ProsperoCompanion` on Windows, `~/Library/Application Support/ProsperoCompanion` on a Mac), so updating or reinstalling keeps it.

## Known issues

- **Built-in recall needs a model file you download yourself.** The Companion suggests EmbeddingGemma 2 and Qwen3 Embedding 0.6B but never downloads a model for you. The llama.cpp builds it fetches for Mac haven't been run on a real Mac yet; on Linux, point `COMPANION_LLAMA_SERVER` at your own llama-server.
- **Not code-signed.** Expect SmartScreen warnings on Windows and a Gatekeeper block on the first Mac run.
- **Mac is untested on real hardware.** The scripts and tests pass on GitHub's Apple Silicon and Intel Macs only. LoRA training isn't available on a Mac.
- **Not yet tried on real setups:** phone access over Tailscale, and the Local Pulse and Culture Pulse lookups (tested against recorded responses only).
- **Image generation** depends on your own backend; Krea 2 workflows for ComfyUI haven't been verified on real hardware.
- **Real-city data** comes from general knowledge and is labeled as estimates.
