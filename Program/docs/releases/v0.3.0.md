Group chats arrive. Bring several companions into one conversation, and each answers from what they actually know, keeping each other's secrets. Every companion can now text you first, closeness is yours to shape, and your phone can join over home Wi-Fi. If you have an earlier version, install over it (or run `update.bat` / `update.command` in a source copy). Your companions and everything they remember are kept, and the first launch makes a verified backup before updating.

## What's new

**Group chats**
- Start a group with any two or more companions from the new Groups view. You can rename it, add someone (from now on, or with everything said so far), remove someone or start fresh with the same people.
- Each companion answers from what they know. What one of them told you privately stays private, and replies arrive one after another at a natural pace, with a little banter.
- **Secrets:** your companions can know things others mustn't find out. A secret is only told to people who know it, and a companion who'd let it slip in front of the wrong person thinks twice. Secrets can be set up from memories, a companion's description or a storyline, and you can edit them, let someone find out, or end them. Turn on **Say when a secret slips out** in Settings if you want a note when one does.
- **How others see them:** every companion and townsperson has a line for how others see them and private lines for how they see themselves, which shape how they come across in a group.
- **Closeness between people:** companions, their circle and the townsfolk they meet grow closer or drift apart with each other through shared history, group chats and storylines. You can tell two companions' backstory when they first meet.

**Every companion can text first**
- All your companions can reach out, not just the one you're talking to, with one shared daily limit so you're never flooded.
- A **Chats** list shows each conversation with its latest message and unread count. Each chat style has its own look for it, and you can hide or resize it. Notifications say who wrote and open their chat.
- Companions learn when you usually show up. If you tend to drop by at lunch, they may ask about your lunch plans, but only when their own day leaves them free.

**Closeness you can shape**
- Step closer or back, set a stage directly, or cap it ("never closer than Friends").
- New companions can start at a chosen stage with a line about how you know each other. Townsfolk you've met often start closer, and Matchlight matches start at "Just met".
- **Keep as a shared moment** on any message counts it toward closeness.
- Optional gentle cooling: after long silences closeness slips a little, and it comes back as you talk again.
- Each stage now feels noticeably different in conversation.

**Branch and edit any message**
- **Branch from here** works on every message, yours and theirs, not just your last one.
- Edit your companion's replies in place. Editing one of yours starts a new timeline from that point.
- The app's own notes (a failed or stopped reply, for example) now sit in a small box of their own, so they never read as your companion speaking.

**Your phone**
- A new optional **Use on home Wi-Fi** mode lets a paired phone connect over your home network. Only use it on a network you trust.
- Phone access over Tailscale now checks your phone and walks you through fixes if nothing loads, with a backup address that works without extra setup.
- On a phone, press and hold a message for a big action sheet. The message box grows as you type and tucks away when you scroll up.

**Cities and errors**
- Los Angeles is now built in, and a new guide explains how to make your own city.
- One bad city file no longer blanks Settings.
- Errors say what failed, why, and what to try.
- Image backends can list the models they offer.

## What's fixed

- Saving a memory no longer gets stuck on an empty "About" field, and "my nickname is…" is picked up automatically.
- A companion you stepped back from no longer makes replies fail when townsfolk encounters are on.

## Install on Windows

**Installer (easiest):** download `ProsperoCompanion-0.3.0-win-x64-setup.exe` below and run it. It installs for your user only and doesn't need administrator rights, Python or Node. It adds Prospero Companion to the Start menu. It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC": click **More info**, then **Run anyway**.

**Portable:** `ProsperoCompanion-0.3.0-win-x64.zip` is the same app without an installer. Unzip it anywhere and double-click `Prospero Companion.cmd` in the `ProsperoCompanion` folder.

**From source:** download the source code below (or `git clone` the repository), open the `Windows` folder, double-click `install.bat` once and then `launch.bat`. It can update itself later with `update.bat`, whether you cloned it or downloaded the ZIP.

Then open **Settings > Models**, add a model, and create your companion. `SHA256SUMS.txt` lists the checksums of the downloads.

## Install on a Mac

There's no Mac app yet. Download the source code below (or `git clone` the repository), open the `Mac` folder and double-click `install.command`, then `launch.command`. It needs Python 3.12+ and Node.js 22.13+ and installs them with Homebrew if you have it. The scripts aren't signed, so a downloaded ZIP needs **Open Anyway** in System Settings > Privacy & Security the first time. [Installing on a Mac](https://github.com/vantaloomin/prosperos-companion/blob/main/Program/docs/macos.md) walks through it.

By default your companion's data lives outside the program folder (`%LOCALAPPDATA%\ProsperoCompanion` on Windows, `~/Library/Application Support/ProsperoCompanion` on a Mac), so updating or reinstalling keeps it. Settings > Data shows where yours is.

## Known issues

- **Built-in recall needs a model file you download yourself.** The Companion suggests EmbeddingGemma 2 and Qwen3 Embedding 0.6B but never downloads a model for you. The llama.cpp builds it fetches for Mac haven't been run on a real Mac yet. On Linux, point `COMPANION_LLAMA_SERVER` at your own llama-server.
- **Not code-signed.** Expect SmartScreen warnings on Windows and a Gatekeeper block on the first Mac run.
- **Mac is untested on real hardware.** The scripts and tests pass on GitHub's Apple Silicon and Intel Macs only. LoRA training isn't available on a Mac.
- **Phone access** over Tailscale or home Wi-Fi is new, and testers have had trouble getting a phone to load. The new checks in Settings > Phone access say what's wrong.
- **Not yet tried on real setups:** Matchlight's Show photo, and the Local Pulse and Culture Pulse lookups (tested against recorded responses only).
- **Image generation** depends on your own backend. Krea 2 with ComfyUI has run on one Windows PC with an RTX 5090. Text inside pictures can come out garbled.
- **Real-city data** comes from general knowledge and is labeled as estimates.
