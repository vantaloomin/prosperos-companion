A fix-up release for v0.5.0, "Word Gets Around", with fixes our Mac testers found and some long-requested Settings polish: color schemes, friendlier number controls, and a quicker way to find a model file you just downloaded. If you have an earlier version, install over it (or run `update.bat` / `update.command` in a source copy). Your companions and everything they remember are kept, and the first launch makes a verified backup before updating.

## What's new

**Color schemes**
- Pick a look in Settings: Ink, Slate, Umber, Moss, Wine or Ash, the same schemes as Prospero's Study. Or make your own palette, and it'll warn you if text would be hard to read. Your phone follows the PC. Retro IM keeps its own messenger colors.

**Friendlier number settings**
- Number settings now use the control that fits. Small counts get + and − buttons, wide ranges get a slider that says the value in words, time spans get a list of sensible choices, and image tuning gets a slider beside a number box. Changes save right away, with no more Save limits button.
- Number boxes can't go past their limits anymore, so a typo can't save an absurdly large number.

**Finding your models**
- Downloaded a model file for built-in recall? Switch back to the app and it notices the new file, or press **Check for models**. ComfyUI file lists refresh the same way.
- Folder paths on screen show your home folder as `~`, so screenshots don't show your user name.

**Image services from your phone**
- A paired phone can now add OpenRouter, Google, the OpenAI API or NanoGPT for pictures with a key typed on the phone, and switch, reorder, check or remove image services. Server addresses, the Codex program and ComfyUI workflows are still set up on the PC. Keys can't be sent over the home Wi-Fi connection, which isn't encrypted, so use Tailscale for that.

## What's fixed

- Memories stay with the right companion. Switching chats while your companion was still remembering something could file it under someone else, especially with a phone open on another chat.
- A reply you stopped partway, or one that got cut short, can now be edited, and your edited version is the one kept.
- When something can only be changed on the PC, the message now says where on the PC to do it.

## Install on Windows

**Installer (easiest):** download `ProsperoCompanion-0.5.1-win-x64-setup.exe` below and run it. It installs for your user only and doesn't need administrator rights, Python or Node. It adds Prospero Companion to the Start menu. It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC": click **More info**, then **Run anyway**.

**Portable:** `ProsperoCompanion-0.5.1-win-x64.zip` is the same app without an installer. Unzip it anywhere and double-click `Prospero Companion.cmd` in the `ProsperoCompanion` folder.

**From source:** download the source code below (or `git clone` the repository), open the `Windows` folder, double-click `install.bat` once and then `launch.bat`. It can update itself later with `update.bat`, whether you cloned it or downloaded the ZIP.

Then open **Settings > Models**, add a model, and create your companion. `SHA256SUMS.txt` lists the checksums of the downloads.

## Install on a Mac

There's no Mac app yet. Download the source code below (or `git clone` the repository), open the `Mac` folder and double-click `install.command`, then `launch.command`. It needs Python 3.12+ and Node.js 22.13+ and installs them with Homebrew if you have it. The scripts aren't signed, so a downloaded ZIP needs **Open Anyway** in System Settings > Privacy & Security the first time. [Installing on a Mac](https://github.com/vantaloomin/prosperos-companion/blob/main/Program/docs/macos.md) walks through it.

By default your companion's data lives outside the program folder (`%LOCALAPPDATA%\ProsperoCompanion` on Windows, `~/Library/Application Support/ProsperoCompanion` on a Mac), so updating or reinstalling keeps it. Settings > Data shows where yours is.

## Known issues

- **Built-in recall needs a model file you download yourself.** The Companion suggests EmbeddingGemma 2 and Qwen3 Embedding 0.6B but never downloads a model for you. The llama.cpp builds it fetches for Mac haven't been run on a real Mac yet. On Linux, point `COMPANION_LLAMA_SERVER` at your own llama-server.
- **Not code-signed.** Expect SmartScreen warnings on Windows and a Gatekeeper block on the first Mac run.
- **Mac is untested on real hardware.** The scripts and tests pass on GitHub's Apple Silicon and Intel Macs only. LoRA training isn't available on a Mac.
- **Phone access** over Tailscale or home Wi-Fi is new, and testers have had trouble getting a phone to load. The new checks in Settings > Phone access say what's wrong.
- **Not yet tried on real setups:** voice notes with real voices, Matchlight's Show photo, and the Local Pulse and Culture Pulse lookups (tested against recorded responses only).
- **Image generation** depends on your own backend. Krea 2 with ComfyUI has run on one Windows PC with an RTX 5090. Text inside pictures can come out garbled.
- **Real-city data** comes from general knowledge and is labeled as estimates.
