**A fix for chat.** In v0.1.0, v0.1.1 and v0.1.2, every chat reply failed with "The reply failed unexpectedly". This release fixes it. If you have an earlier version, install over it (or run `update.bat` / `update.command` in a Git clone); your companion and everything they remember are kept.

## What's fixed

- **Chat replies work again.** Building the reply's context tripped over the townsfolk code added just before v0.1.0, so every reply failed and nothing was logged. A new test covers it. Unexpected reply failures are now written to the log too.
- **Built-in recall is easier to switch on.** The first model file it finds is picked for you, a model file you drop into the folder shows up when you come back to the window, the status reads "Loading the model…" and then "Running on this PC." straight after you turn it on, and a model llama.cpp can't load shows llama.cpp's own reason instead of a crash dump.

For everything that came before, see the [v0.1.2](https://github.com/vantaloomin/prosperos-companion/releases/tag/v0.1.2) and [v0.1.0](https://github.com/vantaloomin/prosperos-companion/releases/tag/v0.1.0) notes.

## Install on Windows

**Installer (easiest):** download `ProsperoCompanion-0.1.3-win-x64-setup.exe` below and run it. It installs for your user only, needs no administrator rights, Python or Node, and adds Prospero Companion to the Start menu. It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC": click **More info**, then **Run anyway**.

**Portable:** `ProsperoCompanion-0.1.3-win-x64.zip` is the same app without an installer. Unzip it anywhere and double-click `Prospero Companion.cmd` in the `ProsperoCompanion` folder.

**From source:** download the source code below (or `git clone` the repository), open the `Windows` folder, double-click `install.bat` once and then `launch.bat`. A Git clone can update itself later with `update.bat`.

Then open **Settings > Models**, add a model, and create your companion. `SHA256SUMS.txt` lists the checksums of the downloads.

## Install on a Mac

There's no Mac app yet. Download the source code below (or `git clone` the repository), open the `Mac` folder and double-click `install.command`, then `launch.command`. It needs Python 3.12+ and Node.js 22.13+ and installs them with Homebrew if you have it. The scripts aren't signed, so a downloaded ZIP needs **Open Anyway** in System Settings > Privacy & Security the first time; [Installing on a Mac](https://github.com/vantaloomin/prosperos-companion/blob/main/Program/docs/macos.md) walks through it.

Your companion's data lives outside the program folder (`%LOCALAPPDATA%\ProsperoCompanion` on Windows, `~/Library/Application Support/ProsperoCompanion` on a Mac), so updating or reinstalling keeps it.

## Known issues

- **Built-in recall needs a model file you download yourself.** The Companion suggests EmbeddingGemma 2 and Qwen3 Embedding 0.6B but never downloads a model for you. The llama.cpp builds it fetches for Mac haven't been run on a real Mac yet; on Linux, point `COMPANION_LLAMA_SERVER` at your own llama-server.
- **Not code-signed.** Expect SmartScreen warnings on Windows and a Gatekeeper block on the first Mac run.
- **Mac is untested on real hardware.** The scripts and tests pass on GitHub's Apple Silicon and Intel Macs only. LoRA training isn't available on a Mac.
- **Not yet tried on real setups:** phone access over Tailscale, and the Local Pulse and Culture Pulse lookups (tested against recorded responses only).
- **Image generation** depends on your own backend; Krea 2 workflows for ComfyUI haven't been verified on real hardware.
- **Real-city data** comes from general knowledge and is labeled as estimates.
