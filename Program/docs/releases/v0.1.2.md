Two new features for the Prospero's Companion early beta. If you have v0.1.0 or v0.1.1, install over it (or run `update.bat` / `update.command` in a Git clone). Your companion and everything they remember are kept; the first launch makes a verified backup of your workspace before updating it.

## What's new

- **Send pictures in chat.** Attach, paste or drop up to four pictures with a message, or send one on its own. They're shrunk and stripped of location data on your PC first. The **Seeing pictures** model in Settings > Models (your conversation model unless you pick another) describes each picture once, so your companion reacts to what it shows and remembers it later. If that model can't see pictures, your companion says it wouldn't load, and a small note under the picture shows the real reason.
- **Built-in recall.** Settings > Models > Built-in recall runs an embedding model on your own PC with llama.cpp, so recall can find related memories without LM Studio, Ollama or an embeddings service. You download the model file yourself (EmbeddingGemma 2 or Qwen3 Embedding 0.6B are suggested); llama.cpp downloads when you ask and is checked against a pinned checksum. It runs on the processor only and stops when the Companion stops. **Test recall** checks whatever handles recall now.
- **Better recall with instruction-trained embedding models.** EmbeddingGemma, Qwen3 Embedding, nomic-embed-text, mxbai and Arctic now get the search instructions they were trained with. Stored memories are re-indexed once in the background.

## Install on Windows

**Installer (easiest):** download `ProsperoCompanion-0.1.2-win-x64-setup.exe` below and run it. It installs for your user only, needs no administrator rights, Python or Node, and adds Prospero Companion to the Start menu. It isn't code-signed yet, so Windows SmartScreen may say it "protected your PC": click **More info**, then **Run anyway**.

**Portable:** `ProsperoCompanion-0.1.2-win-x64.zip` is the same app without an installer. Unzip it anywhere and double-click `Prospero Companion.cmd` in the `ProsperoCompanion` folder.

**From source:** download the source code below (or `git clone` the repository), open the `Windows` folder, double-click `install.bat` once and then `launch.bat`. A Git clone can update itself later with `update.bat`.

Then open **Settings > Models**, add a model, and create your companion. `SHA256SUMS.txt` lists the checksums of the downloads.

## Install on a Mac

There's no Mac app yet. Download the source code below (or `git clone` the repository), open the `Mac` folder and double-click `install.command`, then `launch.command`. It needs Python 3.12+ and Node.js 22.13+ and installs them with Homebrew if you have it. The scripts aren't signed, so a downloaded ZIP needs **Open Anyway** in System Settings > Privacy & Security the first time; [Installing on a Mac](https://github.com/vantaloomin/prosperos-companion/blob/main/Program/docs/macos.md) walks through it.

Your companion's data lives outside the program folder (`%LOCALAPPDATA%\ProsperoCompanion` on Windows, `~/Library/Application Support/ProsperoCompanion` on a Mac), so updating or reinstalling keeps it.

## Known issues

- **Built-in recall needs a model file you download yourself.** The Companion suggests EmbeddingGemma 2 and Qwen3 Embedding 0.6B but never downloads a model for you. The llama.cpp builds it fetches for Mac haven't been run on a real Mac yet; on Linux, point `COMPANION_LLAMA_SERVER` at your own llama-server.
- **Not code-signed.** Expect SmartScreen warnings on Windows and a Gatekeeper block on the first Mac run.
- **Mac is untested on real hardware.** The scripts and tests pass on GitHub's Apple Silicon and Intel Macs only. LoRA training isn't available on a Mac.
- **Not yet tried on real setups:** phone access over Tailscale, and the Local Pulse and Culture Pulse lookups (tested against recorded responses only).
- **Image generation** depends on your own backend; Krea 2 workflows for ComfyUI haven't been verified on real hardware.
- **Real-city data** comes from general knowledge and is labeled as estimates.
